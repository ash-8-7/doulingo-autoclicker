# doulingo-autoclicker
A simple autoclicker written in Python for duolingo
یه پروژه تزیینی که کاربرد خاصی نداره فقط برای سرگرمی و با هوش مصنوعی دیپ سی ساخته شده 
برای اجرا فایل رو دانلود کرده و مثلا با وی اس کد بازش کنید  داخل ترمینال با این دستور پیش نیاز هاش رو دانلود کنید pip install pyautogui pynput
قبلش محیط مجازی رو فعال کنید یا یکی جدید بسازید 
برین داخل مرورگر سایت دولینگو رو باز کنید در زبان انگلیسی به قسمت ساند برین 
کد رو اجرا کنیید و y + enter  رو بزنید موس رو 5 ثانیه روی دکمه استارت نگه دارید بعد دوباره اینتر رو روی ترمینال بزنید و فقظ صبر کنید 
(بهتره یک بار خودتون مرحله رو اجرا کنید و اسپیکینگ رو اسکیپ کنید)
