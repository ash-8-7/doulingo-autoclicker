یک پروژه تزئینیه که کاربرد خاصی نداره و فقط برای سرگرمی ساخته شده؛ البته کدش با کمک هوش مصنوعی DeepSeek نوشته شده.

### نحوه اجرا

فایل پروژه رو دانلود کنید و با مثلاً VS Code بازش کنید. سپس داخل ترمینال، پیش‌نیازهای پروژه رو با دستور زیر نصب کنید:

```bash
pip install pyautogui pynput
```

قبل از نصب، محیط مجازی پروژه (Virtual Environment) رو فعال کنید یا یک محیط مجازی جدید بسازید.

بعد وارد مرورگر بشید، سایت Duolingo رو باز کنید و در دوره زبان انگلیسی، وارد بخش **Sound** بشید.

کد رو اجرا کنید و `y` + `Enter` رو بزنید. سپس موس رو به مدت ۵ ثانیه روی دکمه **Start** نگه دارید. بعد دوباره `Enter` رو داخل ترمینال بزنید و فقط صبر کنید.

بهتره قبل از اجرای برنامه، یک بار مرحله رو خودتون انجام بدید و بخش **Speaking** رو Skip کنید.
